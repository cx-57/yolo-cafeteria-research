# macworx — manually reviewed NHS-compatible subset

Source: https://universe.roboflow.com/macworx/containers-yw7aw/dataset/7

License: CC BY 4.0

Every source image was visually reviewed against the NHS cafeteria object standard. Only accepted image/label pairs belong here.

- Source images reviewed: 420
- Images retained: 121
- Images scrapped: 299
- Target class: `5 = hinged_container`
- Retained object instances: 121
- Segmentation polygons converted to detection boxes: 37
- Native detection boxes retained: 84

Produce/egg packages, reusable containers, retail packaging, label-only examples, foam examples, and incompatible geometries were rejected.
