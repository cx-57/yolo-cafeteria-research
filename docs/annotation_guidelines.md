# Annotation guidelines

Draft; freeze before large-scale NHS labeling.

1. Annotate the complete visible physical object when consistently identifiable.
2. Use the frozen object taxonomy, never the disposal stream, as the label.
3. Label `food` as meaningful visible food masses, not individual crumbs/grains.
4. Do not force labels on ambiguous or severely occluded objects; flag them for review.
5. Use tight bounding boxes without cutting off visible object regions.
6. Record collection metadata separately in the image manifest.
7. QA a fixed sample before training.
