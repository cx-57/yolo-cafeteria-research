# utensil — manually reviewed NHS-compatible subset

Source: https://universe.roboflow.com/lemon-dataset-h2ime/utensil/dataset/1

License: CC BY 4.0

Every source image was visually reviewed against the NHS cafeteria object standard. Only accepted image/label pairs belong here.

- Source images reviewed: 465
- Images retained: 128
- Images scrapped: 337
- Target class: `3 = utensil`
- Retained object instances: 244
- Segmentation polygons converted to detection boxes: 132
- Native detection boxes retained: 110

Metal, colored, transparent, wooden, reusable, bottle, and otherwise non-NHS-compatible examples were rejected.
