# TACO training supplement prepared for bottle research

Prepared and verified; not trained yet. Six unused TACO photographs with
15 clear plastic beverage-bottle boxes passed AI full-image/object-crop review
and the fixed-validation duplicate screen. Four other native-orientation
candidates were held for uncertain material/identity or label completeness;
two more were held for source orientation/dimension issues. These are
experimental training decisions, not human verification.

Combined with the 35 LVIS photos from `../external-data-v8/`, this supplement
has 41 external photos / 80 bottle boxes, 1,097 unique training photos and
1,592 training exposures. The 246-image / 67-box validation set is unchanged.
All original source data and checkpoints remain intact. Lossless PNG source
photos retain their exact bytes with the correct filename suffix; no geometry
or image pixels were silently repaired.

[TACO source](https://github.com/pedropro/TACO): Proença and Simões (2020),
*Trash Annotations in Context for Litter Detection*. Source image URLs and
image-license availability are retained per record; the repository code’s MIT
license is not asserted as a license for every photograph. The official source
annotation file is checksum-bound in `taco-downloads.json`. All automatic
screens are heuristic and do not establish complete capture independence.

No accuracy improvement or independent NHS test score is claimed.
