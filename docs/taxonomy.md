# Object taxonomy

Status: **provisional until the NHS waste audit is complete.**

| Class | Include | Exclude / caution |
|---|---|---|
| food | visible leftovers and food scraps | individual crumbs/grains |
| plate | disposable cafeteria plates resembling NHS serviceware | ceramic restaurant plates |
| paper_boat | open paper/cardboard food boats and cafeteria trays | shipping boxes |
| utensil | disposable forks, spoons, knives | metal restaurant silverware unless NHS uses it |
| compartment_container | disposable sectioned cafeteria trays/containers | generic storage boxes |
| hinged_container | clear disposable hinged/clamshell food containers | household storage containers |
| napkin | disposable cafeteria napkins, including crumpled/soiled | cloth napkins |
| milk_carton | cafeteria milk/juice-style cartons | unrelated cardboard boxes |
| condiment_packet | single-serve sauce/dressing packets | bulk sauce pouches |
| wrapper | cafeteria snack/food wrappers | unrelated film/plastic litter |
| bottle | beverage bottles relevant to NHS waste | unrelated household bottles |

A matching source class name is not enough; public images must be visually plausible in the NHS domain.
